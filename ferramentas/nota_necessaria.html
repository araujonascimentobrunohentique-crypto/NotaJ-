Como calcular a média escolar?

A média escolar é calculada a partir das notas obtidas nas avaliações. Quando todas as avaliações têm o mesmo peso, basta somar as notas e dividir pela quantidade de avaliações.

Como calcular uma média simples?

Na média simples, todas as notas possuem a mesma importância. Por exemplo, se você tirou 6, 7 e 8, a média é obtida somando as três notas e dividindo o resultado por 3.

Como calcular uma média ponderada?

Quando as avaliações possuem pesos diferentes, cada nota tem uma influência diferente no resultado final. Nesse caso, a nota é considerada de acordo com o peso atribuído à avaliação.

Como usar a calculadora de média?

  1. Digite suas notas.
  2. Informe o peso de cada avaliação.
  3. Adicione outras notas, se necessário.
  4. Clique em calcular.

Qual é a diferença entre média simples e ponderada?

A média simples considera todas as notas com a mesma importância. Já a média ponderada considera os pesos de cada avaliação, fazendo com que algumas notas tenham maior influência no resultado.

Posso calcular minha média com pesos diferentes?

Sim. A calculadora do NotaJá permite informar o peso de cada avaliação para calcular a média considerando a importância de cada nota.
